# Novex UI Skills

Install taste-skill and ui-skills for agent-guided frontend development:

```bash
npx skills add https://github.com/saurabh-sol/taste-skill --skill "design-taste-frontend"
npx skills add https://github.com/saurabh-sol/taste-skill --skill "high-end-visual-design"
npx skills add https://github.com/saurabh-sol/taste-skill --skill "full-output-enforcement"
```

Copy ui-skills from http://ui-skills.com into this directory:
- emil-design-eng
- make-interfaces-feel-better
- 12-principles-of-animation
- fixing-accessibility
- shadcn

Taste-skill dials for Novex: DESIGN_VARIANCE=4, MOTION_INTENSITY=5, VISUAL_DENSITY=5
