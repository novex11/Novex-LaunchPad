# Novex Design System

## Colors

| Token | Hex | Usage |
|-------|-----|-------|
| background | `#FAF8F4` | Page background (cream white) |
| surface | `#FFFFFF` | Cards, modals |
| surface-muted | `#F3F1EC` | Secondary panels |
| accent | `#C5D4C0` | Dust green — buttons, badges |
| accent-strong | `#A8BFA3` | Hover, active states |
| accent-subtle | `#E8EFE6` | Stockback callouts |
| foreground | `#0A0A0A` | Primary text |
| muted-foreground | `#525252` | Labels, disclaimers |

## Typography

- Headings: Instrument Serif
- Body: DM Sans
- Monospace: system mono for tx hashes and amounts
